# OKX P2P Калькулятор Маркетмейкинга

Интерактивный калькулятор для расчёта прибыли от P2P маркетмейкинга на бирже OKX с возможностью учета транзакций и анализа прибыли.

![Калькулятор OKX P2P](https://i.imgur.com/JIFdZBj.png)

## Функциональность

- **Калькулятор прибыли** — рассчитывает потенциальную прибыль от маркетмейкинга, основываясь на капитале, спреде, загрузке капитала и количестве оборотов
- **Отслеживание баланса** — ведение учета транзакций с автоматическим расчётом текущего баланса и прибыли
- **Живые рыночные данные** — получение актуальных рыночных цен с OKX через прокси-сервер
- **Анализ рынка** — автоматические рекомендации по ценам на основе текущей рыночной ситуации
- **Графики прибыли** — визуализация динамики баланса и прибыли по времени
- **Экспорт/импорт данных** — возможность сохранения и восстановления данных о транзакциях
- **Темная тема** — автоматическое переключение между светлой и темной темой в зависимости от системных настроек

## Особенности

- Точный расчет прибыли на основе полной истории транзакций
- Учет начального капитала в USDT и UAH 
- Расчет реальной прибыли в режиме реального времени
- Адаптивный дизайн для мобильных устройств
- Работа офлайн с использованием Service Worker
- Поддержка нескольких API эндпоинтов для повышения надежности

## Начало работы

### Предварительные требования

- Node.js (версия 14 или выше)
- npm (входит в состав Node.js)

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Slowpokess/trading-numbers.git
   cd trading-numbers
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите прокси-сервер:
   ```bash
   npm start
   ```

4. Откройте `index.html` в вашем браузере, используя любой локальный сервер или просто двойным кликом на файл.

## Использование

### Калькулятор прибыли

1. Укажите ваш капитал в USDT
2. Задайте ожидаемый спред в процентах
3. Укажите процент загрузки капитала
4. Установите ожидаемое количество оборотов в день
5. Нажмите "Рассчитать прибыль" или воспользуйтесь предустановленными сценариями

### Отслеживание транзакций

1. Перейдите на вкладку "Мои транзакции"
2. Установите стартовый капитал в USDT и/или UAH
3. Нажмите "Обновить стартовый капитал"
4. Добавляйте транзакции, указывая тип (покупка/продажа USDT), сумму, курс и дату
5. Отслеживайте текущий баланс и прибыль

## Структура проекта

- `index.html` — основной файл приложения с интерфейсом и JavaScript кодом
- `server.js` — прокси-сервер Node.js для обхода CORS и получения данных с API OKX
- `service-worker.js` — сервис-воркер для кэширования и офлайн работы
- `package.json` — файл зависимостей npm

## Технологии

- Vanilla JavaScript — без использования фреймворков для облегченного интерфейса
- Express — для прокси-сервера
- Chart.js — для построения графиков
- Service Worker API — для кэширования и офлайн функциональности
